Canvas Notes Web Clipper

Connect this browser to your Canvas Notes server.

What gets sent

The extension transmits information only after you choose a clip command. Depending on that command, it sends the chosen page URL, title, selected text, simplified article text, link, or image to the Canvas Notes server you configure below. Your API token is sent only to that server for authentication.

There is no analytics, advertising, browsing-history collection, background page monitoring, or third-party service.

HTTPS is required except for localhost development.

Create one under Canvas Notes → Settings → API tokens. It is stored locally in Firefox and is never exposed to web pages.

How to clip

  • Select the toolbar icon to clip the page, selected text, or a simplified article.
  • Right-click a page, selection, link, or image and choose Canvas Notes.
  • Press Ctrl + Shift + Y to clip the current page.

Every clip lands unplaced in the Canvas Notes inbox. Supported YouTube URLs become video cards through Canvas Notes’ existing URL handling.
