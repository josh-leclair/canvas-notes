# Canvas Notes Web Clipper Privacy Policy

Effective August 23, 2026.

Canvas Notes Web Clipper sends only the content a user explicitly chooses to
clip to the Canvas Notes server that user configures. Depending on the selected
command, that content is a page URL and title, selected text, simplified article
text, a link, or an image. The configured server URL and Canvas Notes API token
are stored locally in Firefox; the token is transmitted only to that server for
authentication and is not exposed to visited pages.

Transmission occurs only as the direct result of a clearly labeled clip
command. The extension does not monitor pages in the background, collect
browsing history, or transmit analytics, telemetry, crash reports, cookies,
advertising identifiers, or unrelated information. It includes no advertising
or analytics SDKs and does not sell or share data with third parties.

The operator of the user-configured, self-hosted Canvas Notes server controls
the storage, retention, deletion, access, and logging of received clips. Users
can remove local connection details in extension settings, revoke the API token
in Canvas Notes Settings, or uninstall the extension at any time.

Privacy questions may be sent through the support contact published on the
official addons.mozilla.org listing.
