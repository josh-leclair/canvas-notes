Privacy Policy

Canvas Notes Web Clipper · Effective August 23, 2026

Summary

Canvas Notes Web Clipper sends only the content you explicitly choose to clip to the Canvas Notes server you configure. The extension developer does not receive that content.

Data handled

Depending on the command you choose, the extension handles a page URL and title, selected text, simplified article text, a link, or an image. It also stores your Canvas Notes server URL and API token locally in Firefox and sends the token to that server as authentication.

When data is transmitted

Transmission occurs only as the direct result of selecting a clearly labeled clip command. The extension does not monitor pages in the background, collect browsing history, or send analytics, telemetry, crash reports, cookies, advertising identifiers, or unrelated data.

Destination and retention

Data is sent directly from Firefox to the Canvas Notes server URL you entered. Retention, deletion, access, and server logging are controlled by that self-hosted Canvas Notes installation and its operator. Clips are saved to your Canvas Notes inbox.

Local storage and control

The configured server URL and API token remain in Firefox extension storage. They are not exposed to visited websites. You can remove them at any time from the extension settings, revoke the token in Canvas Notes Settings, or uninstall the extension.

Third parties and children

The extension contains no advertising or analytics SDKs and does not sell or share data with third parties. It is a productivity tool and is not directed to children.

Changes and contact

Material changes will be reflected in an updated policy and extension release. Privacy questions may be sent through the support contact published on the official addons.mozilla.org listing.
