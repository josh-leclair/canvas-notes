# Contributing

Bug reports, deployment feedback, and feature discussions are welcome through
GitHub Issues.

Canvas Notes is not accepting external code contributions yet. The project is
dual-license-ready, and accepting code requires a contributor agreement that
preserves both the public PolyForm license and the maintainer's ability to offer
separate commercial licenses. Pull requests submitted before that agreement is
available may be closed without review.

Please do not include private notes, API keys, session secrets, database dumps,
uploaded files, or other user data in an issue or reproduction.
