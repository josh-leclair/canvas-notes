# Security policy

## Supported versions

Security fixes are applied to the latest tagged release. This is a young
project; older releases may not receive patches.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
private vulnerability reporting feature on this repository instead. Include a
description, reproduction steps, affected versions, and the likely impact.

Do not include real user data, credentials, tokens, or production database
contents in the report. Please allow a reasonable period for investigation and
remediation before public disclosure.
